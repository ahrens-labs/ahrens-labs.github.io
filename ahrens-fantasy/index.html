Scoring rules

Set how points are earned.

Default sets the template for every position. Each position follows Default unless you change a specific stat for that position. Changing Default later updates every stat that was never changed for its position. Defaults are full PPR.

Default sets scoring for all positions. A position follows Default unless a stat was changed for that position. CUSTOM badges show stats that differ from Default.
Only stats that differ from Default are stored as customized. Resetting a customized stat back to the Default value removes its override.

YOUR SCORING MODEL

Players earn points for every matching stat in the live feed. Use negative point values for turnovers, fumbles, or points allowed.
